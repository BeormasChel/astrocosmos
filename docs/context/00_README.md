# Проект «Астрокосмос» – Интерактивный образовательный комплекс

## Общая информация

**Название проекта:** Интерактивный образовательный комплекс «Астрокосмос»  
**Тип проекта:** Детский астрономический комплекс нового поколения  
**Целевая аудитория:** Дети и подростки от 6 до 17 лет  
**Ключевой принцип:** *Не просто показать, а вовлечь. Не просто рассказать, а дать потрогать, услышать, увидеть и прочувствовать.*

Проект представляет собой единое интерактивное пространство, объединяющее физические экспонаты (метеорит, фигурки учёных, макеты часов, телескоп) с цифровыми интерфейсами (сенсорные экраны, голографические дисплеи, 3D-модели, видео, голосовое управление, трансляции реальных наблюдений). Все элементы работают под управлением централизованного интеллектуального ядра, что позволяет создавать сценарии занятий и экскурсий, управлять контентом и анализировать взаимодействия.

## Основные цели

1. **Образовательная** – превращение сложных астрофизических концепций в наглядные, интерактивные и увлекательные формы, доступные для восприятия детьми.
2. **Технологическая** – разработка и интеграция **восьми** уникальных интерактивных комплексов, работающих в едильной локальной сети под централизованным управлением.
3. **Экспозиционная** – создание атмосферы космического корабля и обсерватории, где каждый элемент работает на общую нарративную линию.

## Состав комплексов

| № | Название | Логический блок |
|---|----------|----------------|
| 1 | **Малый Голобокс** | Тактильное знакомство с космическим материалом (метеорит) |
| 2 | **Большой Голобокс** | Глубокое погружение в астрофизику через персонажей и технологии |
| 3 | **Настольный помощник «Диптих»** | Голосовое управление, RFID-программатор, система доступа |
| 4 | **Астрономические часы** | Визуализация времени в космосе |
| 5 | **Иллюминатор** | Создание атмосферы присутствия в космическом корабле |
| 6 | **Астровизор** | Экран + Raspberry Pi: трансляция изображения с астрокамеры купола |
| 7 | **Тумба RFID** | Пластиковая тумба с PN532, подключена к Pi **большого** голобокса (не отдельный экран) |
| 8 | **Система управления обсерваторией «Диптих»** | Купол, телескоп, Vizor угла купола; отдельный MQTT; в ядро — позже |

> **Важно:** Комплексы №3 и №8 имеют общее название «Диптих», но совершенно разные по функционалу. №3 – настольный помощник (голосовой, RFID), №8 – комплексная система автоматизации обсерватории (управление куполом, телескопом, датчиками). Они интегрируются через единое ядро, но разрабатываются и эксплуатируются независимо.
>
> **Vizor** (угол поворота купола, комплекс №8) и **Астровизор** (экран трансляции, комплекс №6) — разные системы.

Актуальные аппаратные решения (голобоксы на Raspberry Pi, тумба как периферия №2, два MQTT-брокера) — в [`docs/architecture/pre_dev_decisions.md`](../architecture/pre_dev_decisions.md).

## Технологический стек

- Сервер ядра: любая ОС с Docker; предпочтительно Ubuntu LTS. PostgreSQL, FastAPI, React + TypeScript, MQTT Mosquitto (топики `astroc/`), Celery + Redis.
- Голобоксы №1 и №2: Raspberry Pi, тач-GUI (веб-киоск), видеофрагменты.
- Иллюминатор: Raspberry Pi 5, 4K.
- Астровизор: Raspberry Pi, сетевой захват потока камеры.
- Тумба: PN532 на Pi большого голобокса.
- ESP32 ядра: часы, настольный Диптих, пульт Иллюминатора. Vizor/MCC — только проект №8.
- Речь: Vosk + Piper локально; Yandex SpeechKit — опция.
- Комфорт аудитории: Home Assistant как исполнитель, ядро — оркестратор.
- Обсерватория: свой MQTT-брокер; OpenAPI ещё предстоит спроектировать.
