# Референсы и источники вдохновения для проекта «Астрокосмос»

## Музеи и аналоги

- **Музей космонавтики (Москва)** – интерактивные экспонаты, иммерсивные зоны.
- **Планетарий в Санкт-Петербурге** – цифровой планетарий с полнокупольными программами.
- **California Science Center** – интерактивные экспозиции с использованием сенсорных технологий.
- **Exploratorium (Сан-Франциско)** – музей науки с акцентом на тактильное и экспериментальное обучение.
- **Музей «Экспериментарий» (Калининград)** – уличные интерактивные экспонаты.
- **Обсерватория «Следующая звезда» (Казань)** – автоматизированный купол и управление через приложение.

## Технологии и библиотеки

- **FastAPI** – [официальная документация](https://fastapi.tiangolo.com/).
- **React + TypeScript** – [React Docs](https://reactjs.org/), [TypeScript Handbook](https://www.typescriptlang.org/docs/).
- **MQTT** – [Mosquitto](https://mosquitto.org/), [Paho MQTT](https://www.eclipse.org/paho/).
- **Raspberry Pi** – [официальный сайт](https://www.raspberrypi.com/documentation/).
- **ESP32** – [ESP-IDF](https://docs.espressif.com/projects/esp-idf/) и [Arduino-совместимые библиотеки](https://github.com/espressif/arduino-esp32).
- **FastLED** – [библиотека для светодиодных лент](https://fastled.io/).
- **ReSpeaker** – [HAT для Raspberry Pi](https://wiki.seeedstudio.com/ReSpeaker_2_Mics_Pi_HAT/) (может быть адаптирован для ESP32).
- **Yandex SpeechKit** – [облачный сервис синтеза и распознавания речи](https://cloud.yandex.ru/services/speechkit).
- **Vosk** – [оффлайн-движок распознавания речи](https://alphacephei.com/vosk/).
- **INDI** – [стандарт для управления астрономическим оборудованием](https://indilib.org/).
- **ASCOM** – [стандарт для Windows-совместимых телескопов](https://ascom-standards.org/).
- **OpenCV** – обработка изображений.
- **PyIndi** – Python-библиотека для INDI.
- **AstroPy** – библиотека для астрономических расчётов.
- **OpenAstroTracker** – проект управления монтировкой на Arduino.
- **ROR Observatory automation** – открытые решения для управления куполами.

## Оборудование

- **ZWO ASI** – астрономические камеры.
- **Sky-Watcher, Celestron** – монтировки, поддерживающие ASCOM/INDI.
- **StepStick / A4988** – драйверы шаговых двигателей.

## Контент для Иллюминатора и Астровизора

- Архив [NASA Image and Video Library](https://images.nasa.gov/).
- Видео с визуализацией чёрных дыр, туманностей, пролётов над планетами.

## Педагогические материалы

- «Астрономия для детей» – книги и энциклопедии.
- Курсы на Stepik и других платформах.
- Проект «Астрономия для всех» – программы наблюдений для школьников.
