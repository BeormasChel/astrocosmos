# Глоссарий терминов проекта «Астрокосмос»

## Основные термины

| Термин | Определение |
|--------|-------------|
| **Аккреционный диск** | Диск из газа и пыли, вращающийся вокруг массивного объекта (например, чёрной дыры) и излучающий энергию. |
| **Голобокс** | Интерактивный комплекс с голографическим (или полупрозрачным) дисплеем, позволяющий совмещать реальный объект и цифровую графику. |
| **Иллюминатор** | Комплекс, имитирующий окно космического корабля, с экраном, показывающим виды космоса. |
| **Малый Голобокс** | Комплекс с сенсорным экраном, под которым находится реальный фрагмент Челябинского метеорита. |
| **Большой Голобокс** | Комплекс с большим сенсорным экраном и RFID-считывателем для идентификации фигурок учёных. |
| **Интерактивная тумба** | Напольный экспонат с сенсорным экраном и RFID-считывателем, позволяющий «оживлять» фигурки учёных. |
| **Астровизор** | Уличный интерактивный киоск, имитирующий телескоп и транслирующий изображение с реального астрономического инструмента. |
| **RFID-метка** | Радиочастотная метка, содержащая уникальный идентификатор, используемая для идентификации фигурок учёных и сотрудников. |
| **Челябинский метеорит** | Крупный метеорит, упавший в Челябинской области в 2013 году; в проекте используется его реальный осколок. |

## Технологические термины

| Термин | Определение |
|--------|-------------|
| **MQTT** | Лёгкий протокол обмена сообщениями по модели издатель-подписчик, используемый для управления устройствами в реальном времени. |
| **NTP** | Протокол синхронизации времени по сети. |
| **NFS** | Сетевая файловая система, позволяющая монтировать удалённые каталоги как локальные. |
| **REST API** | Архитектурный стиль взаимодействия компонентов в сети, основанный на HTTP-запросах и передаче данных в JSON. |
| **FastAPI** | Веб-фреймворк для Python, обеспечивающий высокую производительность и автоматическую генерацию OpenAPI-документации. |
| **Celery** | Система для выполнения фоновых задач (планировщик) с поддержкой распределённой работы через очереди. |
| **Redis** | Брокер сообщений и хранилище ключ-значение в памяти, используется Celery для очередей. |
| **OTA (Over-The-Air)** | Технология обновления прошивки устройств без физического доступа, по сети. |
| **ESP32** | Микроконтроллер с поддержкой WiFi и Bluetooth, используемый для управления периферией. |
| **Raspberry Pi** | Одноплатный компьютер, выполняющий функции управления экранами и видео. |
| **Docker** | Платформа для контейнеризации приложений. |
| **Docker Compose** | Инструмент для определения и запуска многоконтейнерных приложений. |
| **INDI / ASCOM** | Протоколы и интерфейсы для управления астрономическим оборудованием. |
| **Монтировка** | Механическая опора для телескопа с приводами наведения. |
| **Азимут** | Горизонтальный угол направления (поворот по кругу). |
| **Высота (альт)** | Угол над горизонтом. |

## Специфические термины для «Диптих»

| Термин | Определение |
|--------|-------------|
| **Диптих (настольный помощник)** | Комплекс №3 – голосовой AI-ассистент, RFID-программатор и система доступа. Расположен внутри помещения. Управляется через MQTT. |
| **Диптих (система управления обсерваторией)** | Комплекс №8 – автоматизированная система управления куполом, телескопом, камерами и климат-контролем обсерватории. Имеет собственное веб-приложение и ESP32-блоки в куполе. Интегрируется в общее ядро через REST API. |

> **Важно:** Эти две системы имеют одинаковое название, но различаются по назначению, местоположению и способу управления. В обсуждениях и документации всегда уточняйте, о каком «Диптихе» идёт речь.

## Научные термины

| Термин | Определение |
|--------|-------------|
| **Сверхновая** | Взрыв звезды на конечной стадии эволюции. |
| **Нейтронная звезда** | Остаток массивной звезды после взрыва сверхновой, состоящий в основном из нейтронов. |
| **Экзопланета** | Планета, вращающаяся вокруг звезды за пределами Солнечной системы. |
| **Красное смещение** | Увеличение длины волны света, свидетельствующее об удалении источника (эффект Доплера в космологии). |
| **Тунгусский метеорит** | Крупное взрывное событие в 1908 году над Сибирью, предположительно вызванное падением метеорита или кометы. |
| **Аризонский кратер** | Хорошо сохранившийся кратер в Аризоне, США, образованный около 50 000 лет назад. |

## Роли в системе

| Роль | Описание |
|------|----------|
| **Администратор** | Полный доступ ко всем функциям: управление пользователями, контентом, обновлениями, просмотр аналитики. |
| **Педагог** | Может запускать готовые сценарии, создавать и редактировать экскурсии, управлять расписанием занятий. |
| **Смотритель** | Ограниченный доступ: только включение/выключение комплексов и базовый контроль. |

## Прочие сокращения
- **БД** – база данных.
- **ИБП** – источник бесперебойного питания.
- **ТТС** – текст-в-речь (синтез речи).
- **STT** – речь-в-текст (распознавание речи).
- **VPN** – виртуальная частная сеть.
- **LED** – светоизлучающий диод.
