# Технические требования проекта «Астрокосмос» (с новыми системами)

## Сетевая инфраструктура

- **Локальная сеть:** все устройства (сервер, RPi, ESP32) должны быть подключены к одной защищённой сети (Ethernet предпочтительнее, WiFi допустим при использовании WPA2-Enterprise).
- **Фиксированные IP-адреса:** каждому устройству назначается статический IP в диапазоне 192.168.1.x (или другой частный диапазон). Рекомендуется использовать DHCP-резервации по MAC-адресам.
- **Открытые порты на сервере:**
  - `8000` – API (внутренний).
  - `3000` – веб-интерфейс админки (может быть проксирован через Nginx).
  - `1883` – MQTT (только локально).
  - `5432` – PostgreSQL (только локально).
  - `2049` – NFS.
- **Безопасность:** все неиспользуемые порты закрыты. Для удалённой поддержки предусмотрен VPN-доступ.

## Энергоснабжение

- **Бесперебойные источники питания (ИБП):** каждый критический узел (сервер, RPi, ESP32) подключается к ИБП, обеспечивающему не менее 15 минут автономной работы (для уличного Астровизора – 30 минут).
- **Общее потребление:**
  - Активный режим (все комплексы включены) – ~1200 Вт (с учётом обсерватории и уличного оборудования).
  - Режим энергосбережения – ~200 Вт.
- Для поворотных механизмов Астровизора предусмотрены блоки питания на 24В/5А.

## Оборудование

### Сервер
- Intel Core i5 (или эквивалент), 16 ГБ ОЗУ, 2×SSD (RAID 1) + отдельный SSD 2 ТБ для контента.

### Raspberry Pi
- **RPi 5 (8 ГБ)** – для Малого и Большого Голобокса, интерактивной тумбы.
- **RPi 4 (4 ГБ)** – для Иллюминатора, Астровизора (в уличном корпусе).
- Активное охлаждение для RPi 5, пассивное для RPi 4.

### ESP32
- Модель: ESP32-WROOM или ESP32-S3 с поддержкой WiFi.
- Питание 5В через USB или внешний стабилизированный источник.

### Специфические модули
- **Настольный Диптих:** микрофонная решётка ReSpeaker 2-Mics Pi HAT (совместима с ESP32 через I2S), динамик 3 Вт, RFID-модуль MFRC522.
- **Астрономические часы:** светодиодные ленты WS2812 (60 LED/м, длина ~1 м каждая).
- **Астровизор (уличный киоск):**
  - Герметичный корпус IP65 с подогревом стекла.
  - Поворотный механизм: два шаговых двигателя NEMA17 с драйверами A4988, датчики Холла.
  - Сенсорный экран 24" (защищённое стекло).
  - Астрономическая камера (ZWO ASI или аналог) с USB 3.0.
- **Интерактивная тумба:** сенсорный экран 32" (IPS, 10-точечный), RFID-считыватель.
- **Обсерваторная система:** уже существующее оборудование (купол, монтировка, камера, датчики, ESP32-блоки) – требования к интеграции см. ниже.

### Дисплеи
- Малый Голобокс: 21.5" Full HD, HDMI.
- Большой Голобокс: 72" (или 65") 4K, HDMI 2.0.
- Иллюминатор: 4K, вертикальная ориентация, HDMI.
- Астровизор: 24" с защитой, HDMI.
- Интерактивная тумба: 32", HDMI.

## Программное обеспечение

- **Сервер:** Ubuntu 22.04 LTS, PostgreSQL 14+, Mosquitto 2.x, Redis, Celery 5.x.
- **Бэкенд:** Python 3.10+, FastAPI 0.100+, Pydantic 2.x.
- **Фронтенд:** Node.js 18+, React 18, TypeScript 5, Vite.
- **На RPi:** Raspberry Pi OS Lite, Python 3, NFS-клиент, MQTT-клиенты, VLC/omxplayer.
- **На ESP32:** Arduino или PlatformIO, библиотеки: WiFi, PubSubClient, FastLED, MFRC522, ArduinoJson.
- **Для обсерваторной системы:** используется её собственное ПО (драйверы INDI/ASCOM, веб-приложение). Ядро взаимодействует через REST API.

## Требования к уличному оборудованию (Астровизор)
- Диапазон рабочих температур: –20°C … +40°C.
- Влагозащита: IP65.
- Молниезащита и заземление.

## Резервное копирование
- Ежедневное (03:00) на внешний диск: БД, конфигурации, метаданные.
- Медиа-файлы – по необходимости.
- Для обсерваторной системы – отдельное резервирование (на её сервере).

## Интеграционные требования для обсерваторной системы
- Общее ядро должно уметь отправлять команды на обсерваторную систему через HTTP-запросы (например, `/api/dome/open`, `/api/telescope/goto`).
- Ядро должно принимать от обсерваторной системы уведомления о статусах (через webhook или MQTT-мост).
- Все обмены защищены (HTTPS, токены).
- Документация API обсерваторной системы должна быть предоставлена для интеграции.
