Интерактивный голографический бокс 72" для образовательного космического центра
Версия: 1.0
Дата: 17 февраля 2026
Назначение: Документ описывает суть, компонентную базу, принципы работы и интеграционные возможности крупноформатного голографического экспоната для использования в образовательной среде Дворца пионеров.

1. Общая концепция экспоната
1.1. Назначение
Интерактивный голографический бокс 72" представляет собой масштабную образовательную платформу, предназначенную для:

Направление	Описание
Групповое обучение	Одновременное взаимодействие до 10–15 человек, возможность коллективного изучения космических объектов
Демонстрация масштабных явлений	Визуализация планет, галактик, космических аппаратов в натуральную величину относительно экрана
Поддержка образовательных программ	Полное покрытие модулей «Астрономия XXI век», «Занимательная астрономия», «Современная астрономия 2.0»
Профориентационная работа	Знакомство с профессиями через иммерсивные 3D-сцены
Исследовательская деятельность	Работа с данными, графиками, симуляциями в групповом формате
1.2. Ключевая особенность (УТП экспоната)
Масштабный «эффект присутствия»: Прозрачный сенсорный экран диагональю 72 дюйма позволяет создавать изображения и анимации, которые визуально парят в воздухе, обеспечивая эффект погружения для всей группы одновременно. В отличие от 21,5-дюймовой версии, этот экспонат рассчитан на коллективное взаимодействие: несколько посетителей могут одновременно касаться разных зон экрана.

1.3. Место в образовательной экосистеме
Комплекс является центральным элементом учебной аудитории и взаимодействует с:

Элемент аудитории	Тип взаимодействия
Интерактивная доска / проектор	Дублирование контента для всей аудитории
Рабочие станции учащихся (ноутбуки/ПК)	Передача данных, синхронизация цифровых дневников
RFID-терминал	Идентификация фигурок ученых и космонавтов
Сервер образовательного контента	Хранение обновлений, видео, 3D-моделей, AssetBundles
Система управления обучением (LMS)	Сбор статистики, отслеживание прогресса
USB-камера (перспективно)	Захват движений для интерактивных симуляций

3.3. Принцип работы с прозрачным экраном
Ключевое правило (наследуется из проекта 21,5"): Экран прозрачен, когда на нем черный фон. Поэтому все фоны в приложении — черные (#000000). Белый фон используется только для кратковременных эффектов (вспышка при переходах).

Фон	Результат
Черный	Экран прозрачный → посетители видят физические экспонаты внутри шкафа
Белый	Экран непрозрачный → экспонаты скрыты (только для спецэффектов)
Дополнительное требование для 72": Угол обзора увеличен, поэтому требуется более высокая контрастность элементов интерфейса для читаемости с разных точек аудитории.

7.1. Концепция
Интеграция USB-камеры для захвата движений пользователей позволит создать интерактивные симуляции с физическим взаимодействием:

Сценарий	Описание
"Прыжки на планетах"	Камера фиксирует реальные прыжки пользователя; на экране аватар космонавта совершает прыжок с учетом гравитации выбранной планеты
"Управление космическим аппаратом"	Движения руками управляют 3D-моделью спутника или ровера
"Исследование кратера"	Наклоны корпуса меняют угол обзора на 3D-ландшафт
