# Стандарты написания кода для проекта «Астрокосмос»

## Общие принципы
- Код должен быть самодокументируемым: имена сущностей должны отражать их суть.
- Сложные участки обязательно комментировать на русском языке.
- Код должен быть модульным, с чёткими границами ответственности.

## Python (бэкенд, скрипты RPi)
- **Именование:** `snake_case` для переменных и функций, `CamelCase` для классов.
- **Документация:** обязательный docstring для каждой функции, класса и модуля (формат Google или Sphinx).
- **Комментарии:** перед каждым логическим блоком внутри функции пиши короткий комментарий на русском, например:
  ```python
  # Получаем текущий сценарий из базы данных
  scenario = await get_active_scenario()
  # Если сценарий не найден, переходим в демо-режим
  if not scenario:
      start_demo_mode()
