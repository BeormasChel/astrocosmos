Vizor-1/2/3 — датчики угла купола **внутри** комплекса №8. В репозиторий ядра не входят.

## 1. Два MQTT-брокера — это норма

- Брокер **ядра** (`astroc/…`) — комплексы 1–7, Docker Compose.
- Брокер **обсерватории** — только Diptich_hub (купол, Vizor, MCC). Ядро его не поглощает и не сливает ACL.
- Астровизор забирает **видео** (RTSP/HTTP) с камеры в куполе, а не телеметрию Vizor.

## 2. Голобоксы: Raspberry Pi, не Windows-runtime Unity

Оба голобокса работают на Raspberry Pi. Сенсорный GUI — обязателен.

**Runtime на Pi (основной путь):** Chromium kiosk + веб-приложение (React).
Контент — готовые видеофрагменты, оверлеи, простая 3D-сцена (glTF) там, где Pi тянет.
Чёрный фон `#000000` для прозрачного ЖК.

**Unity** не запускаем на Pi (нет нормального ARM-плеера и GPU как у RTX).
Unity оставляем **как студию контента**: ролики, анимации метеорита, экспорт glTF.
Подробности: [`holobox_runtime.md`](holobox_runtime.md).

## 3. Тумба — периферия большого голобокса

Пластиковый корпус, встроенный **PN532**. Провод к Raspberry Pi большого голобокса.
Событие `rfid_scan` публикует устройство `bolshoy_golobox`, ядро отдаёт команду
`play_scientist`. Отдельного `device_id=pedestal` в реестре нет.

Программирование меток — настольный Диптих (тот же стандарт PN532 / 13.56 МГц).

## 4. Home Assistant — да, для света и жалюзи; нет — как «мозг»

Настольный Диптих **должен** уметь гасить свет и закрывать жалюзи.

Цепочка:

`голос/кнопка Диптиха → ядро FastAPI → адаптер Home Assistant → устройства комфорта`

Сценарий занятия тоже может содержать шаг «приглушить свет». Источник правды
по сценариям и правам — ядро, не HA. HA не вызывает купол в обход ядра.

См. [`docs/integration/home_assistant.md`](../integration/home_assistant.md).

## 5. Речь — только локально в основном контуре

| Функция | Основной путь | Опция |
|---------|---------------|--------|
| STT | Vosk (русский) | Whisper, если качества не хватит |
| TTS | Piper | Yandex SpeechKit |
| LLM | выкл. в MVP | Ollama позже |

## 6. Иллюминатор — Pi 5, 4K

Плеер с аппаратным декодом, NFS, кэш роликов, автономный Attract Mode.

## 7. Астровизор ≠ Vizor

Астровизор — киоск с экраном и Pi: показать картинку с астрономической камеры.
Поворотный механизм киоска **не** в текущем объёме. Vizor купола — проект №8.

## 8. Обсерватория — позже, OpenAPI ещё нет

Сначала строим ядро 1–7. №8 дорабатывается отдельно; контракт API
проектируем вместе, когда дойдём. Черновик идей:
[`docs/integration/observatory_api.md`](../integration/observatory_api.md).

Сервер ядра: **любая** ОС, на которой стабильно крутится Docker
(Ubuntu LTS предпочтительна, не обязательна).
