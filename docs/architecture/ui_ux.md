# UI и UX ядра «Астрокосмос»

Админка — для **педагога и смотрителя**, не для разработчика.
Киоски — для **детей**, касанием. Два разных опыта, одна визуальная семья.

## Пользователи админки

| Роль | Главный вопрос | Что видит в первую очередь |
|------|----------------|----------------------------|
| Педагог | «Какое занятие запустить?» | Крупная кнопка запуска, ближайшее расписание |
| Смотритель | «Всё ли работает?» | Статусы комплексов, без редакторов |
| Администратор | «Что поменять?» | Материалы, права, расписание |

Когнитивная нагрузка: на каждом экране **одно** очевидное действие.
Термины «эндпоинт», «MQTT», «контейнер» в UI педагога не показываем.

## Информационная архитектура

| Пункт меню | Зачем человеком | Не говорим |
|------------|-----------------|------------|
| Обзор | Что происходит сейчас | Дашборд, мониторинг |
| Занятия | Запуск и остановка сценариев | Pipeline, jobs |
| Комплексы | Состояние 1–7 и тумбы как части №2 | Devices, heartbeat |
| Материалы | Видео, тексты, учёные, метки | CMS, ассеты |
| Расписание | Когда что включится само | Cron, beat |

Обсерватория — не в основном меню, пока нет API: блок «Позже» на Обзоре.

## Визуальная иерархия

1. Заголовок страницы + одна фраза «зачем я здесь».
2. Главное действие (залитая кнопка) — справа наверху или по центру.
3. Карточки комплексов: имя → статус цветом → что делает сейчас.
4. Второстепенное — мельче, ниже контрастом.

Цвет статуса:

- зелёный — на связи
- янтарный — работает с оговоркой
- серый — ждём первое включение
- красный — был на связи и пропал

Не полагаться только на цвет: есть подпись («На связи», «Не включался»).

## Принципы

- **Понятность:** кнопки глаголами («Запустить занятие», «Остановить»).
- **Логичность:** одно и то же действие всегда в одном месте.
- **Минимум шума:** пустые состояния учат («Подключите Иллюминатор — он появится здесь»), а не пугают ошибкой.
- **Адаптивность:** админка от 1100 px — две колонки; планшет педагога — одна колонка, меню снизу или гамбургер.
- **Скорость развёртывания:** `docker compose up`, админка на `:3000`, без клиентских сборок у педагога.

## Киоски (голобоксы, иллюминатор)

См. [`holobox_runtime.md`](holobox_runtime.md). Другой масштаб шрифта и кнопок,
та же палитра (глубокий космос, один акцентный циан, чёрный для прозрачных экранов).

## Стек админки

React 18 + TypeScript + Vite. Состояние сервера — TanStack Query (подключим
с появлением API). Локальный UI — Zustand. Иконки — встроенные SVG, без
тяжёлого UI-kit на старте: так проще выдержать «космический» характер
и не тащить Ant Design в музей.

Шрифты в проде **самохостить** (офлайн площадка). На разработке допустим CDN.
