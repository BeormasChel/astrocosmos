# Малый Голобокс — адаптер к ядру

Устройство: `maly_golobox`. Unity URP, прозрачный 21.5", метеорит.

Ожидаемые команды ядра (черновик):

| Команда | Действие |
|---------|----------|
| `idle` | Заставка |
| `open_section` | Открыть раздел 1–6 |
| `set_lighting` | Яркость LED |

События от Unity: `section_opened`, `idle_timeout`, опционально `rfid_scan`.
