# Админка «Астрокосмос»

Веб-приложение для педагогов и администраторов: контент, сценарии,
мониторинг комплексов, расписание.

Стек: React 18, TypeScript 5, Vite, React Router, TanStack Query, Zustand.

## Запуск

```bash
npm install
npm run dev
```

Админка: http://localhost:3000

## Страницы (план)

| Маршрут | Назначение |
|---------|------------|
| `/login` | Вход (логин/пароль или RFID через настольный Диптих) |
| `/` | Дашборд состояния комплексов |
| `/devices` | Реестр устройств, команды, телеметрия |
| `/scenarios` | Каталог и запуск сценариев |
| `/content` | CMS медиа и текстов |
| `/schedule` | Расписание занятий |
| `/observatory` | Статус обсерватории (read-only + безопасные команды) |
