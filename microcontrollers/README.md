# Прошивки ESP32 «Астрокосмоса»

Только устройства, которыми владеет ядро. Прошивки обсерваторного «Диптиха»
(MCC-1, Vizor-1/2/3, T-Connect, T-Panel купола) **сюда не копируются**.

| Каталог | Устройство | Платформа |
|---------|------------|-----------|
| `planet_clock/` | Астрономические часы, WS2812 | XIAO ESP32-C3 |
| `desktop_diptych/` | Настольный помощник | ESP32-S3 (T-Panel + RFID + голос) |
| `illuminator_remote/` | Сенсорный пульт Иллюминатора | ESP32-S3 |
| `astrovizor_gimbal/` | Поворотный механизм Астровизора | ESP32 + драйверы шаговых |

Сборка: PlatformIO. Общий код (MQTT, OTA, heartbeat) — в `shared/`.
